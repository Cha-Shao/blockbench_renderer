# Blockbench Renderer

Blockbench 桌面版 5.x 插件。最终安装文件为 **`dist/blockbench_renderer.js`**，在 BB「文件 → 插件 → 从文件加载」中选择它。只需这一个文件，渲染引擎及第三方许可已嵌入其中，离线可用，无需额外文件、Blender 或 npm。

## 渲染

主视图区的「显示模式 → 低精度（实时PBR模式）」用于实时编辑预览，可继续选择、移动、旋转和绘画；切回其他显示模式会恢复原材质与灯光。工具菜单只保留一个「渲染」入口，默认高精度 GPU 光追。设置在左侧竖排，右侧预览；按钮在预览下方。

- 渲染：采样次数、降噪，固定使用高精度 GPU 光追，不显示渲染器选择栏。降噪默认开启，使用 GPU 双边滤波减轻噪点并尽量保留边缘；预览和 PNG 导出共用同一设置，透明背景保留原始 Alpha。切换降噪不重置采样，强噪声和极低采样仍应通过提高采样次数改善。
- 输出：分辨率，宽、高分别填写（64–2048 像素）。
- 环境：环境光、透明背景。不生成额外地面。
- 低精度（实时PBR模式）：实时 PBR、环境反射、阴影近似，方便调整视角。
- 高精度（GPU光追模式）：本机 GPU 路径追踪，逐步累积采样。最低 20 轮，默认 128 轮，可选 20 / 32 / 128 / 512 / 1024。高精 PNG 导出至少需要完成 20 轮。
- 支持矩形输出，预览随宽高比例调整。采样进度在预览上方。
- 左键旋转、右键平移、滚轮缩放。改变视角会重新累积采样。
- 预览下方提供「暂停」「重新采样」「导出 PNG」。设置改变会自动应用；模型、贴图或光源修改后重新打开渲染窗口即可。

两个渲染器使用相同模型、颜色贴图、金属度图、粗糙度图和光源。没有自定义光源时使用默认摄影棚光照。高精使用固定版本的 WebGL2 路径追踪库，和 Blockbench 原有 Three.js 隔离。

## 材质和光源

绘画模式颜色面板下方有金属度、粗糙度滑杆。选择基础颜色贴图后，「应用到整张材质」生成两张灰度图；「保存 PBR 贴图」保存为 `<name>_roughness.png` 和 `<name>_metallic.png`。基础贴图已保存时写入同一目录，否则询问目录。同名文件会覆盖。

「随颜色笔画写入 PBR」按普通笔刷和油漆桶的实际覆盖像素同步，颜色相同的重涂或填充也能更新金属度和粗糙度。油漆桶同时记录颜色连通区域的像素写入和面/元素/选区的填充路径。图层绘画暂不做同步，PBR 同步不模拟笔刷透明度混合。两张灰度图可单独选中绘制。请为不同材质使用不同基础名称，并保持三张图分辨率一致。

编辑模式从大纲的「添加 → 添加光源」创建点光、聚光、面光或太阳光，新建默认功率/强度均为 100。光源是真正的大纲对象，可选中、重命名、复制、删除、隐藏、加入组，并使用 BB 原生移动和旋转工具编辑。面光源宽、高通过 BB 原版「变换 → 尺寸」的 X、Y 控件或原生缩放工具调整，Z 厚度为零。光源属性不再重复显示宽高、名称或位置旋转。面光仅向线框法线箭头方向单面发光；宽、高和灯光滚转方向会正确传入渲染。添加和参数编辑支持撤销/重做，随 `.bbmodel` 保存，重开工程时需要加载此插件。

选中聚光灯会出现黄色瞄准点和青色聚焦箭头。拖动黄点或点击属性面板的吸管「对准表面」，可对准任意可见网格的实际表面；隐藏元素会跳过。拖动箭头改变光锥角度。每次拖动是一个撤销步骤，Esc 取消。聚光灯不绑定目标对象方块，也没有跟随目标列表。

面光和太阳光保留对象目标与跟随操作；「照射对象：<模型名称>」按钮用于快速选中已指定的目标，便于编辑，未指定时显示「照射对象：无」，不会限制灯光只照亮该模型。点光源向四周发光，没有 target。辅助线和操作控制点不会进入渲染。16 个 Blockbench 单位对应渲染场景中的 1 米。旧版光源列表会在打开工程时迁移为大纲对象。

## Permission 提示

内置渲染从内存读取模型和贴图，不申请 Node 文件模块权限。保存两张 PBR PNG 需要文件访问；这是 Blockbench 自身的权限提示。「Allow once」不保存授权，「Always allow for this plugin」会记住该插件的对应权限。插件也会缓存本次已授权文件模块，避免同一加载周期内重复请求。

## 限制

主视图实时预览使用真正的单面矩形面光，但不提供面光的遮挡阴影；最终遮挡和间接光请使用 GPU 光追。高精需要 WebGL2 及浮点渲染目标支持，速度取决于 GPU、分辨率、模型和采样数。初始画面有噪点，增加采样会逐渐改善。

当前支持可见静态网格、UV、基础颜色/透明度、粗糙度、金属度。不包含法线贴图、发光贴图、动画批量渲染、自定义 HDRI。实时预览使用主视图区，GPU 光追使用独立插件对话框。

## 开发与验证

`plugin.js`、`lights.js`、`viewport.js`、`renderer.js` 是开发源码。运行 `npm ci`、`npm run build` 生成可分发的单文件 `dist/blockbench_renderer.js`，请勿直接改生成文件。`dist` 仅用于放最终安装产物，用户无需复制源码、测试或 `node_modules`。从早期版本更新时卸载旧的 Cycles 插件，再加载新文件；原有大纲光源类型保持兼容。

`npm test` 用本地 Chrome 的独立无界面实例检查两档真实出图、20 轮采样下限、切换渲染器、尺寸调整、PNG、资源释放。测试脚本当前使用 Windows 默认 Chrome 路径。

已在 Blockbench 5.2.2 实际验证双档渲染、铜色金属贴图、完整立方体导出、采样进度和窗口布局。第三方许可见 `THIRD_PARTY_NOTICES.txt`，也包含在分发文件中。
